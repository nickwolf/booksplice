## Scope and limits

The configure line identifies enabled FFmpeg integration points. It does not prove which optional code paths were exercised, whether a dependency was linked statically or dynamically, which transitive dependencies were included, or that a system API implementation is redistributed. The mappings below therefore do not claim legal completeness. The exact dependency revisions, notices, patent terms, and vendor or platform terms must be checked against the pinned BtbN build sources and the corresponding upstream files before release publication.

FFmpeg reports an LGPL configuration because `--enable-gpl` and `--enable-nonfree` are absent and `--enable-version3` is present. Separately maintained libraries remain subject to their own terms.
