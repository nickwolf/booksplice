# Changelog

## 0.1.0

- Added a Windows drag-and-drop workflow with first-run setup, persistent settings, track-order review, metadata and chapter editing, cover selection, output preview, progress, cancellation, bounded multi-book conversion, keyboard access keys, UI Automation names, and diagnostic export with recognized-path redaction.
- Added deterministic discovery, ordering, metadata aggregation, cover ranking, chapter planning, AAC stream copy, AAC-LC transcoding, validation, atomic publication, and local audit records.
- Added preserve, forced-mono, and forced-stereo channel handling in the GUI and CLI, plus CLI dry runs, newline-delimited JSON events, explicit ordering, metadata-profile selection, full-decode validation, cancellation, and stable exit codes.
- Added deterministic self-contained Windows x64 packaging with pinned LGPL FFmpeg tools, SHA-256 checksums, extracted-artifact smoke testing, and GitHub build-provenance attestations. Two local builds with the pinned toolchain produced the same ZIP digest.
