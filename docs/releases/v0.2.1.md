BookSplice 0.2.1 fixes problems found in real use with updates through a linked install folder, adding several folders at once, how many books the queue converts together, and warnings on clean conversions.

If BookSplice was started through a junction or symbolic link to its folder, for example a `current` link that points at the latest extracted version, the updater could not find its installation and in-app updates failed. BookSplice now resolves the real folder once at startup and uses it for updates. Links inside the folders the updater manages are still refused.

When several folders are picked or dropped at once, all of them now appear in the queue right away as Waiting and are analyzed one after another, with an "Analyzing 2 of 7" line until the last one is done. A waiting folder can be cancelled or removed before its turn. Duplicates and paths that aren't valid are listed one per line instead of stopping the rest. A folder that fails analysis stays in the queue with its own error.

With new or Automatic settings the GUI now converts one book at a time, so the first book finishes sooner. A new Books at once setting under Settings, Advanced settings raises that. Parallel encodes per book (the old Parallel encoding jobs setting) now means the same thing in the GUI as `--jobs` in the CLI: how many source files of one book encode in parallel, which only matters for books with more than 32 files. If you had set Parallel encoding jobs to a number before, 0.2.1 uses that number for Books at once until you change it, and it also stays as the encodes per book. On Automatic, the GUI now runs up to 6 encodes per book where it used to run 1. The settings file stays at schema 1, so going back to 0.2.0 still works.

A normal conversion with chapters and a cover no longer ends as "Conversion complete with warnings". On these files ffprobe prints `stream 0, timescale not set` for the audio stream and `Unsupported codec with id 98314` for the chapter text track. When all required checks pass and the message names the matching stream, it is now kept as a note in the job log instead of counting as a warning. Any other ffprobe message is still a warning. Copy diagnostics now keeps only the last progress block of each FFmpeg run instead of the whole progress stream.

If you already run 0.2.0, open Updates in BookSplice to install this release. If you start 0.2.0 through a link to its folder, start `BookSplice.Gui.exe` from the real folder for this one update, since 0.2.0 still has the link problem, and afterwards start BookSplice from the Start menu shortcut the update creates. Otherwise download `BookSplice-0.2.1-win-x64.zip` and its `.sha256` file, verify the checksum, extract the ZIP, and run `BookSplice.Gui.exe`. Windows may show a SmartScreen warning because this release is not code signed.

Before tagging, this source passed the generated test suite, local verification of a Test-flavor package, and the packaged update rehearsal, including an upgrade and rollback started through a junction. The private long-book, another-volume, and manual Mp3tag checks were not run for this build.
