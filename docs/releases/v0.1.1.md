BookSplice 0.1.1 packages the Windows application and CLI.

The ZIP contains a self-contained WPF application, the `booksplice` CLI, and source-built LGPL FFmpeg tools with their corresponding FFmpeg and zlib source archives, licenses, and rebuild instructions. The GUI supports first-run setup, drag-and-drop analysis, explicit track-order review, metadata and chapter edits, cover selection, per-book output controls, output preview, queued conversion, progress, cancellation, preserve or forced channel handling, full-decode validation, keyboard access keys, per-monitor V2 DPI awareness, diagnostic export with recognized-path redaction, and persistent settings. Existing M4B files remain inspection only.

The release workflow builds from the tag, runs the complete generated-media test suite, verifies the extracted package with a generated AAC-to-M4B conversion, attaches a SHA-256 checksum, and creates a GitHub build-provenance attestation.

Download `BookSplice-0.1.1-win-x64.zip` and its `.sha256` file, verify the checksum, extract the ZIP, and run `BookSplice.Gui.exe`. Windows may show a SmartScreen warning because this release is not code signed.

The exact release ZIP passed the generated test suite and a clean Windows smoke test. The private long-book, another-volume, and manual Mp3tag checks were not repeated for this build.
