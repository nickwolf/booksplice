BookSplice 0.2.0 adds in-app updates, custom metadata profiles, real conversion progress, and a clearer preview and result screen.

BookSplice can now check GitHub for a newer release, show its notes, and install it. Every update is signed, and the new version starts through a small launcher that keeps the previous version until the new one reports it is ready. If the new version fails to start, BookSplice rolls back to the one you had. Updates leave your settings, profiles and logs alone, and other programs can still rename files in the folder BookSplice was unzipped into while an update runs.

Metadata profiles can be defined as JSON files in `%LOCALAPPDATA%\BookSplice\profiles\` and chosen next to the built-in GenericMp4 profile in the GUI and with `--metadata-profile` in the CLI. `docs/METADATA.md` describes the format.

During conversion the queue names the step that is actually running, such as encoding, assembling, checking output, full-decode validation or publishing, with a percentage and remaining-time estimate for that step when it can be measured. If a step stops reporting, the queue says how long it has been quiet without cancelling anything. The CLI `--json` progress events gain the same phase fields; the existing fields are unchanged.

Before converting, the preview now says whether audio will be copied or re-encoded and why, and shows estimated output and temporary space with free space on each drive. The space check now covers the drive that holds BookSplice's temporary files as well as the destination. After converting, the result card shows the outcome, the published path, elapsed time, and the lightweight and full-decode checks separately.

If the GUI hits an unexpected error, it saves a crash report on this computer and closes. On the next start it offers a summary with local paths and credential-looking text removed, which you can copy if you want to share it. Nothing is sent anywhere.

Fixes: segmented conversions of books with more than 32 files kept the wrong duration and chapter positions on speech with long pauses, and folder import and progress display had several problems that are fixed.

Download `BookSplice-0.2.0-win-x64.zip` and its `.sha256` file, verify the checksum, extract the ZIP, and run `BookSplice.Gui.exe`. Windows may show a SmartScreen warning because this release is not code signed. Version 0.1.x has no updater, so this first upgrade is a manual download; later releases can be installed from inside the app.

The release passed the generated test suite, local package verification, and the packaged update rehearsal. The private long-book, another-volume, and manual Mp3tag checks were not run for this build.
